# 结果页资源说明

默认结果页复用 CZUR 会议纪要界面提供的下列图标，均为 PNG，位于 `src/assets/`。
字体使用设备／浏览器已有的中文无衬线字体，不附带私有字体文件。

| 文件 | 用途 |
| --- | --- |
| `original-icon.png` | 原文栏目 |
| `summary-icon.png` | 总结纪要栏目 |
| `todo-icon.png` | 待办事项栏目 |
| `draft-icon.png` | 演示文稿栏目 |
| `speaker.png` | 人物栏目 |
| `play-btn.png`、`pause-btn.png` | 录音播放／暂停 |
| `before15.png`、`after15.png` | 录音后退／前进 15 秒 |
| `copy-btn.png` | 复制内容 |
| `export-btn.png` | 浏览器导出菜单 |
| `share-btn.png` | 复制结果链接 |

合作伙伴可按自己的品牌替换为同名资源，或修改 `index.html`／`result-ui.mjs` 中的路径。
图标只参与显示，不参与协议、身份或模型能力判断；业务含义由按钮文字／无障碍标签提供。
模板不包含 CZUR 私有域名、在线资源或供应商凭据。正式对外发布时，资源授权与其余
参考代码一起按交付协议确认；本文件不额外授予独立商标或品牌使用权。
