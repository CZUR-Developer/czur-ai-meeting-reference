# 数据库运维边界

参考代码只交付 MySQL 5.7 兼容的当前初始化基线
[`migrations/V001__initial_schema.sql`](migrations/V001__initial_schema.sql) 及其执行入口。
本仓不交付数据库容器、数据卷、备份调度、恢复演练或生产运维脚本；这些内容由部署方
按自己的 MySQL 运维规范负责。

参考表统一使用 `ai_trans_*` 前缀，应用启动只做只读 readiness，不自动建表、迁移、
备份或恢复。首次部署前在部署方准备的专用数据库执行 `bash deploy/migrate.sh`，
不要把现有业务库、用户数据或实际备份文件放入参考仓。

本机若需要短期联调，可以自行运行隔离的 `mysql:5.7` 容器并绑定 loopback；容器、
数据卷和测试数据不属于交付物。测试结束后由操作者按其本机环境清理，不影响任何
既有业务数据库。
