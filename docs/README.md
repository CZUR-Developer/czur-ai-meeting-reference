# 文档导航

## 合作伙伴建议阅读顺序

1. [从零接入指南](partner-getting-started.md)：以没有项目背景为起点，准备源码、SDK、
   数据库和模型资源，构建并完成第一场真实字幕会议，再了解交付部署。
2. [模型与能力配置指南](model-and-capability-guide.md)：集中查看完整业务对应的第三方
   平台、申请资源、能力声明、可选组合和缺失后的界面／结果行为。
3. [扩展开发手册](partner-integration-guide.md)：接入自己的登录／鉴权、模型Adapter、
   存储和权益插件、结果动作，以及SDK截图工具。

## 专项说明

- [局域网 HTTPS](local-lan-https.md)：准备开发证书、HTTPS入口、构建地址与Debug信任。
- [后端交付部署](../deploy/README.md)：外部MySQL、唯一V001、Docker应用与外部配置、静态Web。
- [Android App](../android-reference-app/README.md)：模块、运行模式和具体接线。
- [构建／设备工具](../tools/android-device/README.md)：LAN APK构建、原入口启动与结果检查。
- [公共服务端核心](../backend-core/README.md)：共享JAR与宿主装配边界。
- [Web结果页](../web-reference/README.md)：Manifest渲染和人物命名注册扩展。
- [公共协议](../contracts/README.md)：标准数据结构与接口。

各文档分别标明参考已实现、可选样例和伙伴需要提供的部分；没有配置的服务不会自动
使用CZUR账号。文中的域名、地址和凭据均应由部署方替换，真实值不提交到源码仓库。
