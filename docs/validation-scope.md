本文描述首版参考方案的当前范围。默认交付链为 Android App／SDK 直连模型、参考
后端管理会议、MySQL 5.7 保存元数据、Web 回看实际产物。Android 最低支持
Android 14／API 34。运行条件与命令见[从零接入指南](partner-getting-started.md)。

## 交付状态分级

同一功能必须区分以下三种状态，不能互相代签：

- **源码已实现**：参考仓当前 HEAD 有对应代码、单测和构建；不等于设备已验证。
- **历史设备验证**：在当时设备/固件/WebView 上实际跑过；换环境后不自动成立。
- **当前交付保证**：在目标设备、目标固件、目标 WebView、干净数据库和真实后端上本轮
  重新验收通过；这一层才可作为伙伴交付依据。

本轮复验环境：StarryHub Studio50，Android 14／API 34，SN CBP02C2503000002，系统
WebView `com.android.webview 116.0.5845.195`。该 WebView 属于上述已知结果页限制环境。

已修复本轮演示页未交付问题，变化页、稳定页和停止新末帧均有实际会议结果验证。
内置处理仍会按内容决定是否输出，不能将每次调用或每个像素变化等同于必须新增一图；
关闭内置处理可取得原图。默认结果方式保持 Web；PDF 是可选结果插件，开发验收入口
只存在于 Debug 包。目标设备和自己的演示素材仍须按下列步骤验收。

## 目标环境的最小验收

1. 执行唯一 V001 初始化，确认后端存活、数据库就绪和真实能力列表。
2. 构建带目标地址的 SDK App，正常登录；关闭并重开 App，验证登录状态保持。
3. 播放或说出真实语音，确认设置页退出、跨应用悬浮窗实时显示；打开其他应用并操作窗口外
   控件，检查 Mini 恢复和互译大小切换保持同一场；正常停止后立即退窗，结果进入 READY。
4. 通过默认 Web 查看同场实际原文；启用录音时验证播放、拖动、倍速和点击原文定位。
   有总结或演示时切换栏目并预览图片；在目标手机尺寸验证标签和布局，再开启下一场会议。
5. 对启用的翻译、总结和人物能力逐项核对真实产物；关闭相应配置后验证入口及结果区收敛。
   使用有效结果链接点击原文姓名，默认无需重复登录；验证单个／本场全局改名，刷新后检查范围。
   不显示独立人物Tab，有总结时右栏优先显示真实总结。启用声纹时登记一位发言人，
   再用该人的语音新开一场，核对相同 `personId` 和自动姓名。多位说话者或更换音频的
   两场不能直接作为同人命中率样本。没有声纹时仍可本场改名，隐藏下次自动识别选项。
6. 使用演示截图时切换多个明显不同的画面并保留重复画面，核对多图、去重、会议窗口排除、
   正常停止末帧，以及 Web／PDF 中的画面和顺序。普通 Android 不承诺系统级窗口排除。

HDMI-IN、投屏、外设音源和实体方向角依赖匹配的系统能力及现场条件，须在目标硬件
单独验证。最低 Android 版本承诺不包含这些厂商专属能力；标准 MIC 回退也不提供它们。

## 交付与发布边界

参考仓不含真实模型 Key、运行配置、设备签名或闭源 SDK 二进制；配套 AAR 另行取得。
Debug 开发 CA 仅用于本机联调，不进入 Release 信任配置。Release 的签名、公开域名、
第三方服务资源和最终产品验收由部署方负责。后端交付 Docker 应用镜像和外部配置入口，
数据库只交付唯一初始化 SQL，Web 交付静态资源。
