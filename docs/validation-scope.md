# 当前支持范围与验收清单

本文描述首版参考方案的当前范围。默认交付链为 Android App／SDK 直连模型、参考
后端管理会议、MySQL 5.7 保存元数据、Web 回看实际产物。Android 最低支持
Android 14／API 34。运行条件与命令见[从零接入指南](partner-getting-started.md)。

## 功能与验证范围

| 范围 | 当前实现及已有验证覆盖 | 合作伙伴接入时核对 |
| --- | --- | --- |
| 默认会议链 | 本机局域网 MySQL、HTTPS 后端和 Web；登录、恢复会话、真实字幕、停止、结果回看和连续再开 | 使用自己的地址、账号、设备和模型完成同样闭环 |
| 可选模型 | 听悟字幕、中英／中日互译、百炼总结及可选讯飞人物注册／跨场匹配分别有实际验证 | 准确声明当前模型、语言、能力与额度；其他供应商／语言组合需自行验证 |
| 能力缺失 | 字幕最小配置及可选能力降级有模块验证；Web 按实际产物显示 | 不配置翻译、总结、分人、跨场身份时，不出现虚假结果或阻塞基础字幕 |
| 录音与结果 | 保留录音上传、Web 实际播放与拖动续播、原结果链接回看有实际验证 | 目标网络与存储可达，长录音请求体预算和媒体读取满足部署需要 |
| 窗口与生命周期 | 会前 Dialog、字幕浮窗拖动／切换、正常停止退窗、息屏停止及唤醒回看有实际验证 | 目标屏幕尺寸、系统权限及应用生命周期按自己的产品要求核对 |
| 截图 | SDK 公开 Bitmap／File、排窗、可选处理和接受确认有独立设备验证；App 已接入周期／末帧和保存确认 | 独立 API 验证不覆盖完整参考会议的周期／末帧上传及 Web／PDF 图片对照，需在目标部署按下节逐项核对 |

构建、模拟模型、独立 API 和完整真实会议分别验证不同范围，不能相互替代。
这里只声明列出的范围，不对所有 Android 机型、模型或功能组合作普遍保证。

## 目标环境的最小验收

1. 执行唯一 V001 初始化，确认后端存活、数据库就绪和真实能力列表。
2. 构建带目标地址的 SDK App，正常登录；关闭并重开 App，验证登录状态保持。
3. 播放或说出真实语音，确认 App 实时显示；正常停止后立即退窗，结果进入 READY。
4. 通过默认 Web 查看同场实际原文；启用录音时验证播放和拖动，再开启下一场会议。
5. 对启用的翻译、总结和人物能力逐项核对真实产物；关闭相应配置后验证入口及结果区收敛。
6. 使用演示截图时切换多个明显不同的画面并保留重复画面，核对多图、去重、会议窗口排除、
   正常停止末帧，以及 Web／PDF 中的画面和顺序。普通 Android 不承诺系统级窗口排除。

HDMI-IN、投屏、外设音源和实体方向角依赖匹配的系统能力及现场条件，须在目标硬件
单独验证。最低 Android 版本承诺不包含这些厂商专属能力；标准 MIC 回退也不提供它们。

## 交付与发布边界

参考仓不含真实模型 Key、运行配置、设备签名或闭源 SDK 二进制；配套 AAR 另行取得。
Debug 开发 CA 仅用于本机联调，不进入 Release 信任配置。Release 的签名、公开域名、
第三方服务资源和最终产品验收由部署方负责。后端交付 Docker 应用镜像和外部配置入口，
数据库只交付唯一初始化 SQL，Web 交付静态资源。
